# Stage 10 report — Add FC 25, FC 26 and FC 27

## What was done

The game now offers 13 versions, FIFA 15 to EA SPORTS FC 27, with the same rules and the same JSON format as
before. The planning docs (`docs/DECISIONS.md` D53–D56, `docs/BACKLOG.md`, this prompt) were committed as-is in
`6954a49`.

1. **Per-source loaders** (`pipeline/sources.py`)
   - Each source has a small loader that returns the same common frames:
     - **player frame**, with SoFIFA column names: id, short and long name, nationality, age, `club_team_id`,
       positions, overall, `club_position` (or `None`), six face stats and six GK stats;
     - **team frame:** `team_id`, `team_name`, `league_id`, and `overall` (`NaN` when the source has none).
   - `VERSIONS` at the bottom of the file says which loader serves which version:
     - FIFA 15–FC 24: SoFIFA via Kaggle (stefanoleone992), unchanged;
     - FC 25: EA ratings site via Kaggle (nyagami);
     - FC 26: SoFIFA via Kaggle (rovnez);
     - FC 27: EA ratings API via Kaggle (mikedpad), pre-release snapshot of 2026-09-12.
   - `build.py` now only loops over `VERSIONS`. The Best XI, JSON shape, `index.json` and `versions.json` code paths
     are the same as before.
   - **FIFA 15–24 output is byte-identical**: `git diff` shows no change in `app/public/data/15…24/teams.json`, and
     the first 10 entries of `versions.json` and the first 976 of `index.json` are unchanged. The new versions are
     appended.
2. **EA club alias table** (`pipeline/clubs_ea.py`, D54)
   - An explicit table of 117 EA club names → our `team_id` and the display name we already show. It was built from
     the stage 09 majority vote (players' FC 24 club, or FC 26 club for clubs new to the top 5) and checked by eye.
     It covers the unlicensed names: "Lombardia FC" → Inter, "Milano FC" → Milan, "Bergamo Calcio" → Atalanta,
     "Latium" → Lazio.
   - The build fails with the list of names if a top-5 club is missing from the table.
   - Display names come from our FIFA 15–FC 24 data. Nine clubs we never showed before (Como, Coventry City,
     FC St. Pauli, Holstein Kiel, Ipswich Town, Le Mans FC, Paris FC, Racing Santander, SV Elversberg) take their
     FC 26 SoFIFA name.
3. **Names** (`sources.ea_short_name`)
   - `name` is EA's common name when there is one (FC 27 `common_name`; for FC 25, only when the FC 25 name equals
     the FC 27 common name for the same id). It also stays as-is when it is a single word ("Rodri") or ends in
     "Jr." ("Vini Jr.").
   - Otherwise `name` is "F. Lastname", the first initial plus the last name, like SoFIFA's `short_name`.
   - `fullName` is first + last name for FC 27. FC 25 has only one display name, which is used for both.
   - Compared with SoFIFA's `short_name` for the same players (FC 26 / FIFA 15–24 data), the rule gives the same
     name for **95.2% of FC 25 XI players and 98.1% of FC 27 XI players**. The differences are mostly style:
     "M. Cucurella" vs "Marc Cucurella", "D. Jota" vs "Diogo Jota". There is one real miss: Son in FC 25 becomes
     "H. Min Son", because EA writes "Heung Min Son".
4. **GK stats, verified rather than assumed**
   - In both EA files, a goalkeeper's six card slots hold the GK stats in card order: DIV, HAN, KIC, REF, SPD, POS.
   - Evidence:
     - FC 25 `PAC`/`SHO`/`PAS`/`DRI`/`PHY` equal the file's own `GK Diving`/`GK Handling`/`GK Kicking`/
       `GK Reflexes`/`GK Positioning` for 100% of 1,816 GKs.
     - FC 27 `pace`/`shooting`/`passing`/`dribbling`/`physicality` equal its `goalkeeping_*` columns for 100% of
       1,971 GKs.
     - For 1,288 keepers that are in both FC 25 and SoFIFA FC 26, the `DEF` slot correlates 0.96 with SoFIFA's
       `goalkeeping_speed`, against 0.38–0.45 for the other GK stats. Every other slot correlates best (0.92–0.93)
       with its matching GK stat.
   - So speed is the **`DEF`** slot. **This corrects my stage 09 assumption** that it was `PAC`. The stage 09
     report has a correction note.
   - Tests check the mapping on the FC 25 file and on Courtois in FC 27 (87/89/78/90/46/90).
5. **Nations** (`pipeline/nations.py`)
   - New codes: Saudi Arabia `sa`, Indonesia `id`, Malaysia `my`.
   - New `NATION_ALIASES`: Holland → Netherlands, Türkiye → Turkey, Czechia → Czech Republic, Cabo Verde → Cape
     Verde Islands, Guinea-Bissau → Guinea Bissau.
   - The JSON shows the canonical name, so a nation reads the same in every version. The build still fails on any
     unmapped XI nation.
   - New XIs use Saudi Arabia (FC 25–27), Indonesia (FC 26–27) and Malaysia (FC 26).
6. **No EA team sheet in FC 25/27**
   - `eaPos` and `eaFormation` are `null` there, so the "was in EA's XI" tie-break doesn't apply.
   - App types now accept `null` (`types.ts`). No UI code reads either field.
   - FC 26 has a team sheet, so its `eaPos` and `eaFormation` are filled as for FIFA 15–24.
7. **Team `ovr`:** the rounded Best XI average where the source has no team rating (FC 25–27). FIFA 15–24 keep
   SoFIFA's team rating. Teams are sorted by league, then `ovr` descending, then name, which is the same order as
   before.
8. **Versions and labels**
   - `versions.json` has 13 entries. Labels are "EA SPORTS FC 25/26/27", shown as "FC 25/26/27" in compact places.
   - Snapshot dates: 2024-09-26 (FC 25, the archive date, since the file has no date column), 2025-09-19 (FC 26)
     and 2026-09-12 (FC 27).
   - The pickers list newest first and default to FC 27. No app change was needed: the existing code sorts by id.
9. **Validation and tests**
   - `validate.py` covers 15–27, including 18 Ligue 1 clubs for FC 25–27. It allows `null` `eaPos`/`eaFormation`
     only for FC 25 and FC 27, and passes.
   - `pipeline/tests/test_sources.py` has 31 new cases:
     - the version table;
     - the alias table: well-formed entries, unlicensed names, one display name per id, every FC 25/FC 27 top-5 club
       mapped;
     - the name rule (10 cases);
     - the GK mapping, on the FC 25 file and in the FC 27 loader;
     - FC 25 loader fields;
     - age;
     - nation aliases and new codes.
   - The app flag test now expects 13 version files, and it confirms every new `nationCode` has a bundled flag.

## Open issues

1. **The footer credit is out of date (D44).** It still says "Ratings: SoFIFA data via Kaggle (EA Sports FC 24
   complete player dataset)". FC 25 and FC 27 now come from EA's ratings data (Kaggle uploads by nyagami and
   mikedpad), and FC 26 from a different SoFIFA export (rovnez). I didn't change the wording, because D44 fixes it.
   The planning session should decide the new credit line. The README has the same gap.
2. **FC 27 is a pre-release snapshot** (B2). Replace it with the launch-day snapshot if the dataset publishes one.
   Only `FC27_CSV` would change, and the alias table would need any newly named clubs.
3. **Name style differs slightly across sources** for about 2–5% of players: "M. Cucurella" in FC 25 vs
   "Marc Cucurella" in SoFIFA. Son is "H. Min Son" in FC 25. A small override table, or preferring SoFIFA's
   `short_name` for known ids, would fix it. I left it out because the prompt fixes the name rule.
4. **FC 25 has no full names** (`fullName` = EA display name). It's only used as secondary text.
5. **FC 25's snapshot date** in `versions.json` (2024-09-26) is the archive date, not a data column.
6. **FC 26 club names follow our existing names, not the export's.** This export renamed 35 clubs ("AC Milan",
   "Paris Saint-Germain", "Fulham FC", "Real Betis Balompié"…). The loader keeps the names we already show
   for those ids, so a club reads the same in FC 25, 26 and 27. See Assumptions.

## Assumptions not in the prompt

- **Club naming for FC 26:** for clubs we already show, FC 26 uses our existing display name (the latest name in
  the FIFA 15–FC 24 teams file), the same principle as D54. Otherwise 35 clubs would be named differently in FC 26
  than in FC 25 and FC 27. To return to the export's own names, delete the two lines in `load_sofifa_fc26`.
- **Nation names:** aliases resolve to the canonical name already used (e.g. "Holland" shows as "Netherlands"),
  so nations read the same across versions.
- **FC 25 short names:** the "known short form" includes EA's own common name from the FC 27 file, but only when
  FC 25's name is exactly that common name.
- **FC 27 `age`** is computed from `birthdate` on the snapshot date (2026-09-12).
- **Team `ovr`** for FC 25–27 = `round(xiAvg)` (Python rounding).
- **Snapshot date for FC 25** = 2024-09-26, the Kaggle archive date (stage 09).
